A sandbox. Pick elements and set their dials, then collide: the page builds the sound from scratch and plays it. Our detectors then search it without being told the recipe. A control run removes one element at a time, and the detector must stop finding it. This is for listening and exploring; official results still come from the Python code in pts/.
