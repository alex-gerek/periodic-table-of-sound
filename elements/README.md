# Element studies

Each element of the table gets one folder here, named by its symbol and name, for example `Pu_pulse/`.

Every study has the same parts:

1. **Definition** in our own words, with the element's group, period and typical τ.
2. **Measurement math**, derived from scratch.
3. **Ground-truth test** on synthetic signals with known values.
4. **Real-stem test** on GRAVITY and Metro.
5. **Held-out check** on Pure voltage.
6. **Audible demo**: a synthesised example, then "solo this element" from a real track.
7. **Measured τ** and whether the element falls into its predicted cell.

When a study is done, the element's status and τ in the table are updated from its numbers.

Suggested order (from the roadmap): Harmonic pattern, Body, Formant and Timbre motion, Vibrato and Glide, Register, Excitation, Grit, Flutter, Beating, Shimmer, Drift, then the unstable elements.
